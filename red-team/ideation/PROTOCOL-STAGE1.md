# Stage 1 protocol: idea generation (each agent works independently)

1. Read `red-team/ideation/BRIEF.md` and skim the four earlier SYNTHESIS files it lists. Don't read other stage-1 reports.
2. Generate many ideas through your assigned lens; keep the **best 4**. At least one should be bold or non-obvious.
3. Score each kept idea on this **common rubric** (so ideas from different agents can be compared):

| Field | What to give |
|---|---|
| One-liner | What it is, who pays |
| Why now (2026) | The shift that opens it |
| Unfair inputs | What *this founder* has that most don't (be specific; mark weak spots) |
| Market & model | Size, pricing, revenue model, comparables (verified where possible) |
| Capital & structure | Bootstrap / VC / PE / debt; amount; founder ownership after dilution |
| Outcome distribution (10 yrs) | P(fail), P(modest), P(good), P(great) with founder-wealth values in A$; compute expected value and a median |
| Time to replace $500k | Months/years; can it start while employed? |
| Job satisfaction | Day-to-day work; fit with CS/stats/CFO/builder; energy |
| Key risks | Top 3, and what kills it |
| 90-day test | Cheapest proof or kill, with thresholds |

4. End with **your top pick and why**, and a ranked list of the four.
5. Write to `red-team/ideation/stage1/<NN>-<slug>.md` (path in your role). 2,000–3,500 words. Write the file early and update as you go.
6. When done, reply with only: your top pick (one line), the four ideas (one line each with EV), and the file path.
